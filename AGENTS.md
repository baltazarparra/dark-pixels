# AGENTS.md

## Visão geral
Projeto de jogo 2D em JavaScript com Kaboom, servido como site estático.

## Setup e execução
- Instalar deps: não há dependências
- Iniciar servidor local: `python3 -m http.server 8000`
- URL local: http://localhost:8000/

## Testes
Não há suíte de testes configurada.

## Estilo de código
- JavaScript sem ponto e vírgula
- Funções pequenas e focadas
- Evitar duplicação de lógica entre cenas

## Observações
- O projeto usa carregamento de assets direto em runtime
- O arquivo de entrada é index.html
