# 🌘 Dark Pixels

Jogo de plataforma vintage com espírito souls-like, feito em JavaScript.

Demo: https://baltazarparra.github.io/dark-pixels/

![image](https://github.com/baltazarparra/dark-pixels/assets/7395304/580b1f8f-45e5-4b16-9d17-8abc6a79e231)

## Rodar localmente

Este projeto é estático e não precisa de instalação de dependências.

```bash
python3 -m http.server 8000
```

Abra: http://localhost:8000/

## Controles

- Andar: A / D
- Pular: W
- Ataque: Espaço ou clique
- Dash: S
